# 検証

1. `make check` を実行する。
2. 失敗したら原因を直して、もう一度実行する。通るまで繰り返す。
3. 振る舞いを変えた場合は、実際に動かして確認する（例：`make run ARGS="-name Gopher"`）。
4. 結果を短く報告する。実行したコマンドと、通ったかどうかを書く。

## 守ること

- テストを通すために、テストを消したり弱めたりしない。テストが間違っているなら、理由を説明する。
- lint の警告を `nolint` で消さない。必要な場合は理由をコメントに書く。
- 検証できなかった部分は、できなかったと報告する。
